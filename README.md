# Nosso Amor ❤ — contador do casal (React + Vite + Tailwind)

## Rodar
    npm install
    npm run dev        # desenvolvimento
    npm run build      # gera a pasta dist/ para publicar

## Personalizar
Tudo em `src/config.js`: nomes, data/hora de início e a lista de fotos.
As fotos ficam em `public/img/` (ex.: `public/img/foto1.jpg` → `"foto1.jpg"` no config).
